# Social Media Icons

This directory contains colored social media icons in SVG format.

## Icons Included

All icons are already created with official brand colors:

1. **Facebook** - `facebook.svg` ✅
   - Color: Facebook blue (#1877F2)

2. **Twitter** - `twitter.svg` ✅
   - Color: Twitter blue (#1DA1F2)

3. **Instagram** - `instagram.svg` ✅
   - Color: Instagram gradient (purple to pink to yellow)

4. **YouTube** - `youtube.svg` ✅
   - Color: YouTube red (#FF0000)

5. **Pinterest** - `pinterest.svg` ✅
   - Color: Pinterest red (#BD081C)

6. **LinkedIn** - `linkedin.svg` ✅
   - Color: LinkedIn blue (#0077B5)

## Usage

These icons are used in the footer component (`footer.component.html`) and are automatically loaded as image files. The icons maintain their brand colors and are optimized for display on dark backgrounds.

## Replacing Icons

If you need to replace any icons, simply overwrite the corresponding SVG file in this directory. The icons should be:
- SVG format (recommended) or PNG
- 24x24px or 32x32px viewBox
- Colored with official brand colors
