# Apple Touch Icons

This directory should contain Apple Touch Icons for iOS devices.

## Required Files

Please add the following Apple Touch Icon files:

- `apple-touch-icon.png` (180x180px) - Primary icon for modern iOS devices
- `apple-touch-icon-57x57.png` - Legacy iOS
- `apple-touch-icon-60x60.png` - Legacy iOS
- `apple-touch-icon-72x72.png` - Legacy iOS
- `apple-touch-icon-76x76.png` - Legacy iOS
- `apple-touch-icon-114x114.png` - Legacy iOS
- `apple-touch-icon-120x120.png` - Legacy iOS
- `apple-touch-icon-144x144.png` - Legacy iOS
- `apple-touch-icon-152x152.png` - Legacy iOS
- `apple-touch-icon-180x180.png` - Modern iOS (can be same as apple-touch-icon.png)

## Quick Setup

1. Use your logo image (square, preferably 512x512px or larger)
2. Resize to each required size
3. Save as PNG files with the exact names listed above
4. Place all files in this directory (`src/assets/images/`)
